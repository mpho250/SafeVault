# SafeVault – Secure User Management Application

## Project Overview
SafeVault is a C# application developed to demonstrate secure coding practices and protect user information against common security vulnerabilities.

## Security Features
- Input validation.
- SQL injection prevention using parameterized queries.
- Secure authentication.
- Authorization and Role-Based Access Control (RBAC).
- Cross-Site Scripting (XSS) prevention.
- Security testing.

## Vulnerabilities Identified
- SQL Injection
- Cross-Site Scripting (XSS)
- Unauthorized access
- Invalid user input

## Security Improvements
The application applies input validation, parameterized SQL queries, secure authentication, role-based authorization and safe output handling to reduce security risks.

## Testing
Security tests will be included to verify input validation, SQL injection prevention, authentication, authorization and XSS protection.

## Microsoft Copilot Assistance
Microsoft Copilot assisted with generating secure code, implementing authentication and authorization, identifying vulnerabilities, suggesting security fixes and developing security tests.
